# Быстрый старт — KION RL на Java 21+

Проект целиком написан на Java: компактная GPT-2-подобная последовательная рекомендательная модель, reward model и RL-дообучение методом REINFORCE с KL-регуляризацией.

**Важно:** GitHub содержит исходники и текстовые результаты экспериментов. Готовый исполняемый JAR **не хранится в Git** (см. `.gitignore`), поэтому после клонирования его нужно собрать через Maven.

## Требования

- **JDK 21 или новее** (в том числе JDK 25 LTS).
- **Maven 3.9+**.
- Интернет для автоматической загрузки KION при первом запуске либо заранее скачанный архив `interactions.csv.zip`.

В `pom.xml` задан `<maven.compiler.release>21</maven.compiler.release>`: сборка создаёт байткод Java 21, который можно запускать на совместимых Java 21+ JVM. **Устанавливать именно JDK 21 вместо работающего JDK 25 не требуется.** Важно, чтобы и Maven использовал JDK 21+.

Проверьте версии в терминале Windows:

```cmd
java -version
mvn -version
```

## 1. Клонирование и сборка (Windows CMD)

```cmd
git clone https://github.com/noslav7/kion-rl-java.git
cd kion-rl-java
mvn clean package
```

После успешной сборки исполняемый файл находится в `target\kion-rl-java-1.0.0.jar`.

Если проект уже клонирован и собран, первые команды повторять не нужно.

## 2. Запуск воспроизводимого medium-профиля

```cmd
java -Xmx4g -jar target\kion-rl-java-1.0.0.jar --medium --output outputs\kion-medium
```

При первом запуске программа загружает архив KION из [официального репозитория](https://github.com/irsafilo/KION_DATASET) и сохраняет его локально. Обучение и оценка выполняются на **реальных** взаимодействиях. Параметры medium-профиля: seed=42, до 5 000 пользователей, 300 объектов, до 2 000 train-примеров, 3 эпохи SFT и 500 RL-шагов на вариант.

Результаты записываются в `outputs\kion-medium\`:

- `metrics.csv` — сопоставление SFT, reward reranking и RL;
- `EXPERIMENT_REPORT.md` — протокол, качество reward model, метрики и пятишаговая генерация;
- `run_config.txt` — параметры запуска;
- файлы `*.bin` — обученные веса (не публикуются в Git).

В репозитории уже сохранены текстовые результаты одного реального medium-запуска; повторный запуск на другой платформе не гарантирует побитово идентичные значения.

## 3. Если автоматическая загрузка данных недоступна

Скачайте `interactions.csv.zip` из [KION_DATASET](https://github.com/irsafilo/KION_DATASET), затем передайте путь к существующему ZIP:

```cmd
java -Xmx4g -jar target\kion-rl-java-1.0.0.jar --medium --data "C:\path\to\interactions.csv.zip" --output outputs\kion-medium
```

## 4. Быстрая проверка на реальном KION

Сокращённый запуск (не основной исследовательский результат):

```cmd
java -Xmx3g -jar target\kion-rl-java-1.0.0.jar --max-train 300 --sft-epochs 1 --rl-steps 60 --max-eval 70 --output outputs\kion-fast
```

Синтетический smoke-test служит **только** для проверки работы конвейера; его нельзя использовать как экспериментальные результаты на KION:

```cmd
java -cp target\classes ru.research.kion.Experiment --demo --sft-epochs 1 --rl-steps 10
```

## Что важно для интерпретации

- Реализован **уменьшенный GPT-2-style Transformer**, а не предобученная оригинальная GPT-2.
- Reward model предсказывает долю просмотра; её оценка нового действия не равна фактическому отклику пользователя.
- Увеличение predicted reward после RL не доказывает улучшения удержания или удовлетворённости.
- Результаты относятся к ограниченному каталогу и подвыборке KION; для причинных выводов необходимы дополнительные проверки, в том числе онлайн-эксперимент.
